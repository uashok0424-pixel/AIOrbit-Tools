## 📌 Project Overview

AI Orbit Tools Directory is a full-stack web application built as a complete AI Tools discovery module.

The application provides a premium dark interface for discovering AI tools across coding, productivity, research, design, video, audio, and writing categories.

The frontend communicates with a Node.js and Express REST API, which serves the AI tools dataset.
